# আমার পাড়া (Amar Para)

> **গ্রামের/পাড়ার নিজস্ব নোটিশ বোর্ড — সোশ্যাল মিডিয়ার মতো, কিন্তু সোশ্যাল মিডিয়া না।**

## প্রকল্প পরিচিতি

**আমার পাড়া** একটি স্থানীয় অনলাইন নোটিশ বোর্ড। একই গ্রাম ও পাড়ার মানুষ এখানে—

- সাহায্য চাইতে পারে (মিস্ত্রি দরকার, শিক্ষক দরকার, কাজের লোক দরকার)
- জিনিস বিক্রি করতে পারে
- হারানো জিনিসের খোঁজ দিতে পারে
- মসজিদ ও কমিউনিটির নোটিশ দিতে পারে
- বাড়ি ভাড়া ও নতুন উদ্যোগের খবর দিতে পারে

**কে ব্যবহার করবে:** গ্রামের সাধারণ মানুষ — যাদের ফেসবুক আছে বা নেই, সবাই। প্রত্যেক ব্যবহারকারীর নিজের অ্যাকাউন্ট, নিজের পোস্ট ও প্রোফাইল থাকবে। ফিডে সবার পোস্ট একসাথে দেখা যাবে।

**আয়ের ব্যবস্থা:** দোকানের বিজ্ঞাপন, পেইড পিন (পোস্ট উপরে রাখা) ও মেম্বার ফি।

## প্রযুক্তি

| অংশ | প্রযুক্তি |
|---|---|
| ব্যাকএন্ড | Python **FastAPI** + Uvicorn |
| ফ্রন্টএন্ড | **Angular** + NgRx + Tailwind CSS (nginx দিয়ে পরিবেশন) |
| ডাটাবেস | **PostgreSQL 16** |
| চালানো | **Docker** + Docker Compose |


## চালানোর ধাপ

### ১. Docker দিয়ে চালানো (সবচেয়ে সহজ, সুপারিশকৃত)

```bash
# ১) এই ফোল্ডারে আসুন
cd amar-para

# ২) পরিবেশ ফাইল বানান
cp .env.example .env
# তারপর .env খুলে POSTGRES_PASSWORD ও SECRET_KEY অবশ্যই বদলান

# ৩) সব সার্ভিস বিল্ড করে চালু করুন
docker compose up --build

# বন্ধ করতে: Ctrl+C, তারপর
docker compose down
```

চালু হলে:

- ফ্রন্টএন্ড (ওয়েবসাইট): http://localhost:4200
- ব্যাকএন্ড API: http://localhost:8000
- API ডকুমেন্টেশন (Swagger): http://localhost:8000/docs
- ডাটাবেস: localhost:5432

### ২. Docker ছাড়া লোকালে চালানো

```bash
# ডাটাবেস: PostgreSQL 16 চালু করে amar_para ডাটাবেস ও amarpara ব্যবহারকারী বানান

# ব্যাকএন্ড
cd backend
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp ../.env.example ../.env       # মান বদলান, DATABASE_URL-এ localhost ব্যবহার করুন
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload

# ফ্রন্টএন্ড (আরেকটি টার্মিনালে)
cd frontend
npm install
npm start                        # http://localhost:4200
```

## প্রথম অ্যাডমিন বানানো

রেজিস্ট্রেশন ফর্ম থেকে প্রথম ব্যবহারকারী বানান, তারপর ডাটাবেসে তার ভূমিকা অ্যাডমিন করে দিন:

```sql
-- psql বা অন্য কোনো ডাটাবেস টুলে চালান
UPDATE users SET role = 'admin' WHERE username = 'আপনার_ইউজারনেম';
```

এরপর ওই অ্যাকাউন্ট দিয়ে লগইন করলে অ্যাডমিন ড্যাশবোর্ড দেখা যাবে।

## ⚠️ OTP / ফোন যাচাই সম্পর্কে সতর্কতা

- **ডেভ মোডে (`SMS_PROVIDER=log`):** OTP আসলে কোনো ফোনে যায় না — OTP সার্ভারের লগে দেখা যায়, অথবা টেস্ট এন্ডপয়েন্টে দেখা যায়। এটি শুধু ডেভেলপমেন্ট ও টেস্টের জন্য।
- **প্রোডাকশনে:** আসল SMS provider বসাতে হবে। `.env` ফাইলে `SMS_PROVIDER` ও `SMS_API_KEY` দিতে হবে। না দিলে ফোন যাচাই চলবে না — কেউ রেজিস্ট্রেশন সম্পূর্ণ করতে পারবে না।
- রেজিস্ট্রেশন ও লগইনের জন্য **যাচাই করা ফোন নম্বর আবশ্যক**।

## ⚠️ পেমেন্ট সম্পর্কে সতর্কতা

- **পিনের ১০০ টাকা এখন শুধু রেকর্ড হয়।** পিনের অনুরোধ, মেয়াদ ও টাকার হিসাব ডাটাবেসে সংরক্ষিত হয়, কিন্তু আসল টাকা আদায় হয় না।
- **আসল পেমেন্ট গেটওয়ে (বিকাশ / নগদ / SSLCommerz) এখনো বসানো হয়নি।** কারো কাছ থেকে টাকা নেওয়ার আগে অবশ্যই পেমেন্ট গেটওয়ে বসাতে হবে। গেটওয়ে ছাড়া কেউ টাকা পাঠালেও সিস্টেম তা জানবে না।

## পোস্টের নিয়ম

| নিয়ম | বিবরণ |
|---|---|
| দৈনিক সীমা | একজন ব্যবহারকারী দিনে সর্বোচ্চ **২টি** পোস্ট দিতে পারবেন |
| পিন | **১০০ টাকা / ১০ দিন** — পিনের জন্য অ্যাডমিনের অনুমোদন লাগবে |
| মেয়াদ বাড়ানো | পিনের মেয়াদ **৫ দিন বাড়াতে ১০০ টাকা** — অ্যাডমিনকে দিতে হবে |
| মেয়াদ শেষ | **১০ দিনে** সমাধান না হলে পোস্ট **ডাস্টবিন** সেকশনে চলে যাবে (ফিডে আর দেখা যাবে না) |
| সমাধান | সমাধান হলে পোস্ট **সমাধান** সেকশনে যাবে |
| নেগেটিভ ফ্ল্যাগ | একটি পোস্টে **৫টি নেগেটিভ/অশ্লীল কমেন্ট** জমা হলে পোস্টটি **স্বয়ংক্রিয়ভাবে মুছে যাবে** |
| খারাপ পোস্ট | খারাপ পোস্টের খবর অ্যাডমিনের কাছে যাবে; শুধু **অ্যাডমিনই** মুছতে পারবেন |

## অ্যাডমিন ড্যাশবোর্ড

অ্যাডমিন যা যা করতে পারেন:

- ব্যবহারকারী দেখা ও পরিচালনা করা
- পোস্ট ও কমেন্ট পরিচালনা (মোছা, পিন অনুমোদন)
- খারাপ পোস্টের রিপোর্ট দেখা ও ব্যবস্থা নেওয়া
- পরিসংখ্যান ও গ্রাফ দেখা (বার গ্রাফ, মোট বৃদ্ধি/গ্রোথ)

## মেয়াদ শেষের জব চালানো

পুরনো পোস্ট ডাস্টবিনে পাঠানোর জবটি হাতে চালাতে:

```bash
curl -X POST http://localhost:8000/jobs/expire-posts
```

> নিয়মিত চালানোর জন্য সার্ভারে একটি ক্রন/শিডিউলার দিয়ে প্রতিদিন একবার এই এন্ডপয়েন্ট ডাকার ব্যবস্থা করুন।

## সমস্যা সমাধান

| সমস্যা | সমাধান |
|---|---|
| **পোর্ট ব্যস্ত** (`port is already allocated`) | অন্য কোনো প্রোগ্রাম 4200 / 8000 / 5432 পোর্ট ব্যবহার করছে। ওই প্রোগ্রাম বন্ধ করুন, অথবা `docker-compose.yml`-এ হোস্ট পোর্ট বদলান |
| **DB চালু না হওয়া** (backend বারবার রিস্টার্ট হচ্ছে) | `docker compose ps` দিয়ে দেখুন db `healthy` হয়েছে কি না। `docker compose logs db` দেখুন। `.env`-এ `POSTGRES_PASSWORD` ঠিক আছে কি না যাচাই করুন |
| **backend-এ সংযোগ ত্রুটি** | `docker compose logs backend` দেখুন। `DATABASE_URL` ঠিক আছে কি না যাচাই করুন (Docker-এ হোস্ট নাম `db`, localhost নয়) |
| **ফ্রন্টএন্ড খালি পাতা দেখাচ্ছে** | `docker compose logs frontend` দেখুন। backend চালু আছে কি না যাচাই করুন |
| **OTP আসছে না** | ডেভ মোডে OTP ফোনে যায় না — সার্ভার লগে দেখুন (`docker compose logs backend`)। প্রোডাকশনে `SMS_PROVIDER` ও `SMS_API_KEY` বসানো আছে কি না যাচাই করুন |
| **সব ডেটা মুছে নতুন করে শুরু করতে** | `docker compose down -v` (⚠️ এতে ডাটাবেসের সব ডেটা মুছে যাবে), তারপর আবার `docker compose up --build` |
